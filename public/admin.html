🧪 Test chữ ký LGE

Gọi thử 1 GET + 1 POST tới LGE để kiểm tra chữ ký hiện tại còn hợp lệ không. Nếu fail → xem Chẩn đoán để biết cần làm gì.

Chỉ user có signing key mới test được.

ℹ️ Hướng dẫn khi test fail

401 / signature error: Format chữ ký đã đổi. Kiểm tra body encoding, field order, algorithm.

401 / token / expired: Token hết hạn — user cần login lại để có probe token mới.

Bundle mismatch: User ký với bundleId cũ — bấm "Reset Key" user đó.

NET (không kết nối): Đổi LGE Base URL hoặc server đang down.

404: Endpoint đổi path — kiểm tra lại LGE update gần nhất.
